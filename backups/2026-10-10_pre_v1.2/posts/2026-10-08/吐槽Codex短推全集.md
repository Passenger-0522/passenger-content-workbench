### 篇目一：【.git 垃圾爆炸】偷塞几十 G 幽灵快照

今天被 OpenAI Codex 这个 VS Code 插件彻底整破防了，顺手看了一眼项目目录，.git 文件夹居然被它塞了整整十几 G 的缓存垃圾

查了才发现这玩意儿每次对话都在后台偷偷往 refs 里塞 turn-diffs 快照，不仅硬盘被吃得一干二净，打开 SourceTree 和 Git GUI 直接报 bad object 崩溃闪退

写代码的工具先把版本控制给搞瘫痪了，最后我还得去终端跑命令帮它擦屁股清垃圾，简直离谱到家！

---

### 篇目二：【侧边栏假死】Reload Window 地狱

用 Codex 插件最搞心态的，就是它那个日常白屏的 Webview 侧边栏，用着用着就卡死在加载圈里动弹不得

你辛辛苦苦敲了一大段提示词，回车一按毫无反应，或者眼睁睁看着消息凭空蒸发，一天下来我在 VS Code 里敲 Reload Window 的次数比我敲回车还多

明明是来帮我提高效率的，结果我一半时间都在伺候它的玄学假死，血压真是蹭蹭往上涨！

---

### 篇目三：【生态精神分裂】逼得老手全去敲终端

最搞笑的是 Codex 官方自己的工具生态，简直就是大型精神分裂现场

自研的那个 VS Code 插件卡得像幻灯片，发热让风扇狂转，遇到复杂逻辑直接装死，逼得老玩家最后全跑去用黑框框里的 Codex CLI 命令行

图形化界面做得一塌糊涂，最后反而是最原始的终端最好用，这倒退十年的体验到底是谁在吹啊！

### 篇目四：【牛皮癣 CodeLens】手滑误触直接卡死

代码里随手写个 TODO，头上立刻蹦出一个硕大的 Implement with Codex，真是被这个牛皮癣功能给烦死了

只要一不小心手滑点到，它马上开始转圈抢占编辑焦点，想取消还得等它反应半天，关都关不掉

这种强行刷存在感的产品设计到底是谁想出来的，生怕别人不知道你装了个 AI 插件是吧！

### 篇目五：【薛定谔的云端】一键委派变成冲突地狱

还有那个吹上天的云端委派功能，用一次就被恶心一次

最后排查冲突的时间比自己手敲代码还长，真是薛定谔的云端自动化，谁用谁当冤大头！
