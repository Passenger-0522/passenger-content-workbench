# ⚡ 个人内容工作台 (Personal Content Workbench)

> 基于 **Google Gemini 3.8 Flash** 底座 + **TikHub 全网热点聚合** + **自适应历史口吻克隆** 构建的高频内容生产力工作台。
> 专为达成 **每日至少 20 篇爆款文案** 的 KPI 设计。

---

## 🌟 核心功能模块

### 1. 🔥 TikHub 热点雷达与爆款选题漏斗
- **多平台聚合**：内置 TikHub API 连接器，支持抖音热搜榜、小红书高赞榜、TikTok 国际趋势、微博热搜。
- **Gemini 3.8 Flash 爆款降维转化**：根据您设定的垂直赛道定位，将实时热点一键转化为具备高好奇心、反直觉反差感、强痛点的爆款选题。
- **人机协同选题漏斗**：卡片式筛选流程（待筛选 ➔ 入选待写 ➔ 淘汰废弃），亦支持自建原创灵感选题。

### 2. 💡 行文思路共创工坊 (人定思路，AI提纲)
- **3 套破题思路策略生成**：
  - **颠覆认知流 (击碎常识)**：反直觉钩子 + 剖析认知盲区 + 底层逻辑；
  - **保姆级实操流 (抄作业清单)**：痛点代入 + 3步法清单 + 避坑建议；
  - **扎心故事流 (底层复盘)**：亲历痛点 + 转折顿悟 + 升华金句。
- **高度自由定制**：自由修改开篇前 3 秒 Hook、增减核心论述要点、定制结尾 CTA，并可注入您的“独家观点与必提案例”。

### 3. 🎭 历史口吻克隆与人设引擎
- **历史爆款样本库 (Few-Shot Corpus)**：录入您以往发布的真实爆款文案。
- **AI 语言指纹深度解构**：Gemini 深度提取您的：
  - 口吻基调（辛辣直接、大白话直击本质、不讲废话）；
  - 标志性词汇与口头禅（如“本质上”、“闭环”、“信息差”、“别盲目盲从”）；
  - 排版呼吸感与短句断句（每段不超过2-3行，视觉留白极度舒适）；
  - 标点与 Emoji 习惯（使用 💡、🔥，拒绝连用感叹号与公文腔）；
  - 自动编译为专属 System Prompt，彻底杜绝“AI 味”。

### 4. ✍️ 爆款流水线与创作台 (冲刺日更 20 篇 KPI)
- **单篇精修工坊 (Studio Mode)**：左侧大纲与人设画像，右侧文案编辑器；配备多备选标题、快捷 AI 润色（更犀利、小红书排版、强化互动）、字数统计与一键复制。
- **极速批量流水线 (Batch Pipeline)**：专为日更 20 篇打造！批量勾选 10-20 个入选选题，一键全自动并发跑完文案撰写，自动计入今日 KPI。

### 5. 📊 KPI 达成雷达与合集导出
- **实时 KPI 仪表盘**：动态进度环、今日已完成篇数、剩余倒计时、今日总字数统计与打卡天数。
- **一键合集导出**：一键将今日全部 20 篇文案打包导出为 Markdown 文件或复制到剪贴板，方便直接分发至自媒体排版工具。

## 🚀 启动与访问方式

系统已在后台自动运行中：

- **前端界面**：[http://localhost:5174](http://localhost:5174) (或 5173)
- **后端 API**：[http://localhost:3001](http://localhost:3001)

### 手动启动命令：
```bash
# 根目录下安装依赖
npm install

# 一键同时启动前后端服务
npm run dev
```

---

## ⚙️ 核心参数配置 (右上角 ⚙️ 图标)

1. **Gemini API Key**：填写您的 Google AI Studio 密钥（或兼容的代理 Base URL）；
2. **Gemini 模型**：支持选择 `gemini-3.8-flash`、`gemini-2.5-flash`、`gemini-1.5-flash` 等；
3. **TikHub API Key**：填写从 `tikhub.io` 获取的 Token（未填写时自动启用高质量本地热点雷达模拟源）；
4. **每日 KPI 目标**：默认设定为 20 篇/天，可自由调整。
